# Stylish Analog Clock

A stylish analog clock with smooth animations and a ticking sound effect. Built with **HTML, CSS, and JavaScript**, this clock displays the current time with animated hands and a real-time date display.

## 🎨 Features
- 🕰️ **Smoothly animated clock hands** (hour, minute, second)
- 🔊 **Realistic ticking sound** on every second
- 📅 **Displays the current date** in a stylish format
- 🌈 **Modern and responsive UI** with a sleek glassmorphic effect
- 🌙 **Gradient background** for an elegant touch



## 🛠️ Technologies Used
- **HTML5** for structure
- **CSS3** for styling and animations
- **JavaScript** for clock functionality
